# CCNA_Notes

**CCNA command reference as a single offline HTML file — so you never have to hunt for a forgotten command again.**
**جمع‌آوری دستورات CCNA در یک فایل وب — تا دیگر برای یادآوری دستورات فراموش‌شده وقت نگذارید.**

---

## 🇬🇧 English

CCNA_Notes is a self-contained, single-file web page that collects Cisco CCNA commands, configuration tables and memory aids for Routing & Switching — organized in learning order. Download the file, open it in any browser, done. No server, no installation, no internet needed.

### ✨ Features

- 📄 **Single-file & offline** — one HTML file, works in any modern browser
- 🌐 **Two languages** — full English and Persian (فارسی) versions
- 🧭 **Sticky table of contents** with active-section highlighting
- 🌙 **Automatic dark mode** (follows your system theme)
- 📋 **Copy button** on every code block — one click copies the command
- 🖨️ **Print-friendly** stylesheet for paper notes
- 📊 Config tables, notes and warning callouts throughout

### 📚 Topics Covered

The notes are organized in 6 parts, 25 sections:

1. **Fundamentals & Device Management** — CLI modes, common commands, hardening, SSH, IOS upgrade via TFTP, factory reset
2. **Switching** — VLAN / Trunk / Inter-VLAN routing, STP election rules, RSTP, PortFast, BPDU Guard, EtherChannel, PoE
3. **Routing** — Static routes, Administrative Distance, OSPF, EIGRP (CCNA level)
4. **IP Services** — DHCP on a Cisco router, ACLs, NAT
5. **Redundancy & WAN** — FHRP / HSRP, GRE tunnels
6. **Security** — Port Security, DHCP Snooping & DAI, AAA
7. Plus a **quick CCNA summary** for review

### 🚀 Usage

1. Download [`CCNA_Notes_English.html`](CCNA_Notes_English.html) or [`CCNA_Chat_Persian.html`](CCNA_Chat_Persian.html).
2. Double-click to open it in your browser (Chrome / Firefox / Edge).
3. Use the table of contents to jump to a topic; hover a code block and click **copy**.
